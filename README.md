# Infinite Path Puzzle

A progressive path-connecting puzzle game with procedurally generated levels.

![Game Preview](https://img.shields.io/badge/React-18.2-blue) ![TypeScript](https://img.shields.io/badge/TypeScript-5.2-blue) ![Vite](https://img.shields.io/badge/Vite-5.0-purple) ![TailwindCSS](https://img.shields.io/badge/TailwindCSS-3.3-cyan)

## ✨ Features

- **Procedural Generation**: Every level is algorithmically generated
- **Progressive Difficulty**: Grids expand with increasing waypoints
- **Intuitive Controls**: Touch & mouse support with backtracking
- **Celebration Effects**: Confetti and sound on completion
- **Premium UI**: Modern design with smooth animations

## 🎯 How to Play

1. **Draw** a path by clicking/dragging through the grid
2. **Connect** all numbered waypoints in order (1→2→3...)
3. **Conquer** the level when all waypoints are hit!
4. **Backtrack** by dragging backwards to undo moves

## 🛠️ Tech Stack

- **React 18** - UI framework
- **TypeScript** - Type safety
- **Vite** - Build tool
- **TailwindCSS** - Styling
- **SVG** - Game rendering
- **Web Audio API** - Sound effects
